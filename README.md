# TARS AI

TARS AI is an intelligent conversational assistant built with Python, leveraging GPT-based AI to enable natural language understanding and responses, which was inspired by the movie *INTERSTELLAR (2014) si-fi movie*

## Features
- Conversational AI for real-world applications.
- Integration with GPT APIs for dynamic responses.
- Extensible design for future enhancements.

## Technologies Used
- Python - The core programming language for the project.
- GPT API (e.g., OpenAI) - For intelligent conversational abilities.
- Selenium - Used for automation testing and web interactions.
##Other Libraries:
- pyjokes - To generate jokes.
- pytube - For downloading and handling YouTube content.
- gTTS - For text-to-speech conversions.
- SpeechRecognition - For voice input processing.
- Requests - For making API requests.
